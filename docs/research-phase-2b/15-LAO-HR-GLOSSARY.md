## 17 — Names, addresses, phones

### Names
- **Lao naming**: Given name + Family name (Western order). In formal/official contexts, family name may come first.
- **Current LaoHR**: `Employee.LaoName` + `Employee.EnglishName` (single fields each).
- **Recommendation**: P2 — split into `FirstNameLao`, `LastNameLao`, `FirstNameEn`, `LastNameEn` for sorting, document generation, formal addressing. Add `Title` (ທ້າຽ/ນາງ/ທ້າວ), `PreferredName`, `SearchName` (normalized).
- **Do NOT impose** MiddleName unless evidence shows it's needed (Lao doesn't typically use middle names).

### Addresses
- **Hierarchy**: Province (ແຂວງ) → District (ເມືອງ) → Village (ບ້ານ). VERIFIED — LaoHR has this.
- **Gaps**: No `StreetAddress` (house number + street), no `PostalCode` (Laos uses 5-digit codes, e.g., 01000 Vientiane), no `Country` (for foreign employees). P2.
- **Display order**: Village, District, Province, Country (Lao convention) or Province > District > Village (administrative). Both used.
- **Seed data**: `DbSeeder.SeedAddresses` fails on PostgreSQL (SQL Server syntax). P1 — port to PG.

### Phones
- **Country code**: +856. VERIFIED.
- **Mobile**: `020 XXXX XXXX` (prefix 020). HIGH confidence.
- **Landline**: `021 XXX XXX` (Vientiane). MEDIUM.
- **E.164**: `+85620XXXXXXXX` (drop leading 0, add +856). VERIFIED best practice.
- **Current LaoHR**: `Employee.Phone` (free text). GAP: P2 — add validation + E.164 normalization.

## 18 — Unicode & search

### Lao Unicode
- Block: U+0E80–U+0EFF. VERIFIED.
- Abugida: consonant + combining vowel/tone marks. VERIFIED.
- NFC recommended (combining marks). HIGH.
- No case (case-insensitive search N/A for Lao script). VERIFIED.
- LTR. VERIFIED.

### Normalization
- Input may arrive in NFD (decomposed) from copy/paste or different keyboards.
- **Recommendation**: Normalize to NFC on input (.NET: `text.Normalize(NormalizationForm.FormC)`), storage, and search comparison. P2.

### PostgreSQL + Lao
- **ICU collation**: `CREATE COLLATION lo_LA (provider = icu, locale = 'lo_LA')` — HIGH (ICU supports Lao).
- **pg_trgm**: Works but Lao quality MEDIUM (trigrams split syllable clusters). Use GIN index + adjust `similarity_threshold`.
- **Full-text search**: `simple` dictionary (no Lao stemmer). MEDIUM.
- **ILIKE**: Works for Latin; for Lao, normalization matters.
- **Verdict**: pg_trgm + ICU collation on existing PostgreSQL is sufficient. No Elasticsearch. VERIFIED recommendation.

### Search experiment design (future)
1. Exact Lao name search (with NFC normalization).
2. Partial Lao name search (pg_trgm fuzzy).
3. Lao + Latin transliteration (search "Somphon" → find "ສົມພອນ").
4. Combining-character differences (NFC vs NFD same name).
5. Misspelling tolerance (missing tone marks).
6. Village/district/province search.
7. Knowledge article full-text search.
