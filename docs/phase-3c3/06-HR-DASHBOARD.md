# 06 — HR Dashboard

## API
`GET /api/analytics/hr` (Admin/HR).

## Content
- KPI cards: Active Employees, Inactive, New Hires (YTD), Pending Leave.
- Headcount by department / location / position.
- Leave days by type.
- New hires trend.

## Frontend
`/analytics/hr` — KPI grid + breakdown columns.

## Authorization
Admin/HR only.
