# 20 — Reports / Exports

## Curated reports (deferred UI, documented)
Requisition Summary, Candidate Pipeline, Interview Schedule, Offer Status, Hiring Summary, Source Summary, Onboarding Status.

## Export
CSV (UTF-8, Lao Unicode) / Excel (ClosedXML). Sensitive export requires same access scope. Audit sensitive candidate exports.

## Mass export
No ordinary hiring manager can export the entire candidate database (server-side scope).

## No generic report builder
Curated reports only.
