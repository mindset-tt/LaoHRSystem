# 14 — Recruiter UX

## Workspace
`/recruitment` dashboard: open requisitions, open openings, candidates, pending offers.

## Candidate detail
Profile / Applications / Documents / Interviews / Evaluations / Offers / Timeline (tabs, not one enormous page).

## ATS Kanban
Pipeline board (columns = stages). Desktop columns, mobile grouped list, keyboard "Move to Stage". Drag/drop not mandatory.

## Search/filters
Candidate search (name/email/phone), filters (opening/position/department/stage/status/recruiter/hiring manager/source/date). Authorization scope always intersects filters.
