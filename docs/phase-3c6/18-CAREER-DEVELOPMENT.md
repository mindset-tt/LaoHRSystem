# 18 — Career Development

## Model
`CareerInterest` (EmployeeId, Interests, FutureRoles, DevelopmentInterests).

## Aspiration ≠ promise
Career interest is not a promotion commitment.

## Career path
Uses Position structure (current → possible next). No hardcoded universal ladder. `PositionCareerPath` relationship deferred.

## Readiness
Human-approved (READY_NOW, READY_1_2_YEARS, DEVELOPING, NOT_ASSESSED). No algorithmic promotion decision.

## Authorization
Employee manages own career interest. HR/Admin view talent/readiness.
