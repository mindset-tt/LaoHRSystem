# 10 — Competency Framework

## Model
`Competency` (Code, Name, NameLao, Description, Category, IsActive).

## Categories
`Core`, `Leadership`, `Functional`, `Technical`.

## Proficiency levels
1 Awareness, 2 Basic, 3 Working, 4 Advanced, 5 Expert (no arbitrary percentages).

## Authorization
HR/Admin manage the library; all authenticated users can read active competencies.
