# 08 — Milestones / Schedule

## Milestone
Zero-duration checkpoint (Name, DueDate, Status, Owner). Existing entity preserved.

## Project phases
No Phase entity — Milestone + task hierarchy suffice. Not added.

## Schedule health
- `DELAYED`: project due date passed and not completed.
- `AT_RISK`: any overdue task.
- `ON_TRACK`: otherwise.

Documented formula (no arbitrary labels).
