# 11 — RAID

## Existing
- Risks (Likelihood × Impact = Score, Priority, Mitigation, Owner, Status).
- Issues (Status, Priority, Assignee, DueDate, Resolution).

## Added (Phase 3C4)
- `ProjectAssumption` (Description, Owner, Status OPEN/VALIDATED/INVALIDATED, ValidationDate, Outcome).
- `ProjectDecision` (Decision, Context, Owner, DecisionDate, Outcome).

## Not duplicated
- Task dependencies are NOT RAID dependencies (separate concept).
- Actions are represented by Tasks (no separate ActionItem).

## Unified UI
RAID tabs: Risks / Issues / Assumptions / Decisions (domain concepts kept separate).
