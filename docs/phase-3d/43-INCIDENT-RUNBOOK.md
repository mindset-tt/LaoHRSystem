# 43 — Incident Runbook

## Severity levels
- SEV1: outage / data loss / security breach.
- SEV2: degraded (partial outage, slow).
- SEV3: minor (non-critical bug).

## Response
1. Detect (alerting — see 23).
2. Triage + assign.
3. Contain (stop bleeding, isolate).
4. Mitigate (restore service).
5. Root-cause analysis (RCA).
6. Post-mortem + action items.

## Contacts
- On-call rotation (to be defined).
- Escalation path (to be defined).

## Follow-up
- Define on-call + escalation.
- Define SLAs per severity.
- Document incident template.
