# 46 — Operations Runbook

## Daily
- Check health + alerts.
- Verify backup succeeded.
- Review error logs.

## Weekly
- Review metrics (latency, error rate).
- Review disk usage.

## Monthly
- Apply security patches (dependencies).
- Review access/permissions.
- Test restore (quarterly minimum).

## On-demand
- Rotate secrets (12).
- Renew certs (44).
- Scale resources.

## Follow-up
- Define runbook owner.
- Automate routine checks.
- Document escalation (43).
